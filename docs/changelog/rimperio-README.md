# Changelog

Der Verlauf von RIMPERIO steht in [`releases.md`](releases.md) — ein Eintrag je
Release, neueste Version oben, datumsbasiert
(`JAHR.MONAT.TAG.STUNDE.MINUTE.SEKUNDE`).

Kategorien: **Neu**, **Geändert**, **Behoben**, **Entfernt**, **Sicherheit**.
Ein Eintrag sagt, *was* sich geändert hat und *warum* — bei Fehlerbehebungen mit
der Ursache. Die Version wird dort mitgezogen, wo sie steht: [`VERSION`](../../VERSION),
`backend/app/config.py` (`app_version`), `frontend/package.json`,
`agent/internal/core/config.go` (`Version`).
